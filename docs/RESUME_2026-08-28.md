## Where the artifacts live

**`~/.cache/manga-tl-erasure-eval/`** — copied out of the session scratchpad, which lives in `/tmp`

- `scripts/` — every measurement script, plus `eval20.json` (the 21-page results) and `sel.json`

  threshold can be re-swept **without re-running the model**), and 3-panel previews (`_prev.png`)
- `models/ctd_seg_dyn.onnx` — the trimmed dynamic-input seg subgraph (md5 `a04531ab54c9d1dd649ad776e4633163`)
- `models/lama_aot.onnx` — AOT inpainter (md5 `6ab7888cae8bbd96adcd3df177f58645`)
- `an/` — diagnostic images (`miss136.png` = CTD hits vs misses)

**Scripts expect to run from their own directory** and reference the corpus by absolute path.
`ctd.py` reads `CTD_MODEL`, `CTD_SIZE`, `CTD_THREADS` from the environment; it defaults to
`./models/ctd_seg_dyn.onnx`, so either run from a directory with a `models/` symlink or set
`CTD_MODEL`.

### Rebuilding the models from scratch

```
curl -L -o ctd.onnx https://github.com/zyddnys/manga-image-translator/releases/download/beta-0.3/comictextdetector.pt.onnx
# md5 165141f94293c24f5ed2074369d72a6a, 94,669,756 bytes
python3 extract.py     # needs `onnx`; writes models/ctd_seg_dyn.onnx
```
`extract.py` calls `onnx.utils.extract_model(..., ['images'], ['seg'])` then rewrites the input and
output spatial dims to `h`/`w`. `onnx` is not in the project venv — it was installed to a scratch
`--target` directory and is NOT preserved. Reinstall with `pip install --target ./pylibs onnx`.
