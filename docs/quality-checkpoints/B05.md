## Implementation decision

The write path validates the full B01 document before touching storage, then locks the target page and checks all of:

1. `scene_kind` is `logical`.
2. Contract `page_id` equals the route UUID.
3. Contract revision equals `pages.scene_revision`.
4. Contract source SHA-256 equals the page image hash.

It persists snapshot, owner/action rows, and asset identity rows in one transaction. A retry with the same logical digest returns the existing document; a different document at the same revision is `409 Conflict`. Reads join `pages.scene_revision`, so they return only the current immutable snapshot. Revision advancement remains C02 work.
