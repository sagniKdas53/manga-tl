## Change

Added `backend-rust/src/page_freshness.rs` with `advance_page_revision`. A caller supplies its open PostgreSQL transaction and page UUID; the helper atomically sets `last_edited_at`, increments `scene_revision`, and returns that exact revision. It does not commit, enqueue work, write an artifact or alter any route. `backend-rust/src/lib.rs` exports the module for the upcoming route packets.
