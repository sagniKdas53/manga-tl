# C02-R4a: versioned project archives

Status: **DONE**.

Exported browser project archives now write `schemaVersion: 1`. Both archive restore routes require exactly this version before any page/layer/image mutation; missing or unsupported versions return a clear `400`/archive error. Current exports therefore re-import, while unknown payload schemas are rejected rather than guessed.

Focused checks passed:

- `npm test -- src/__tests__/components/ReaderExportZip.test.tsx`
- `./scripts/test-env.sh run cargo test --test import_export_endpoints image_archive_upload_and_project_restore`

The import regression verifies a version-1 archive restores its translated element and a version-2 archive is rejected. Test services were removed.
