# R4 — Torii reference harness

Status: **DONE** (2026-09-17). Tracker: [2026-09-17 realignment](../output-quality-implementation-tracker.md#2026-09-17-realignment--one-live-path).

## What it is

`scripts/quality/reference_compare.py` scores a run's pages against the source, Torii's per-box `metadata.json` and `inpainted.png`, and the `ref-torii*.png` renders. Per page: region rows vs distinct bboxes vs Torii boxes, largest region as a share of the page, greedy IoU matching, visible translation elements per region, hidden Translation layers, refusal text, `altered`/`flattened` from the existing `scripts/render_quality_metrics.py` (thresholds measured 2026-08-05), mean gray difference to Torii's inpainted plate inside our region bboxes, Torii font px, cost. Flags: `WIPE-REGION` (a region > 25 % of the page — the R2 gate), `WIPE-PIXELS` (flattened > 5 %), `FLATTEN-REGRESS` (> 3 %), `DUP-REGIONS`, `DUP-ELEMENTS`, `HIDDEN-LAYERS`, `REFUSAL`, `REGION-COUNT` (distinct regions outside ±30 % of Torii).

No provider calls, no stack. Runs in ~20 s for six pages with the repo-root `.venv` (cv2).

```
.venv/bin/python scripts/quality/reference_compare.py --run docs/quality-runs/g5-20260917-final-six
.venv/bin/python scripts/quality/reference_compare.py --baseline sample177 sample222 sample61 sample99 sample93 sample83 --label august-baseline
```

## Limits

- Torii boxes are the boxes Torii's editor drew (possibly user-adjusted); IoU is a proxy for ownership, not a label. Human A06/A06-C labels still decide ownership.
- `vs inpainted` includes text pixels on both sides; compare ours against the Torii column on the same page, not across pages.
- `ours font px` is empty on every current page because elements are `autoSize` with `size: null`; the resolved size is not persisted. R1's scene diagnostics should carry it.
- Refusal detection is a short regex; it caught the three `sample222` refusals and nothing else. Extend when a new pattern appears rather than broadening it now.
