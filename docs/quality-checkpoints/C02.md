## Frozen C02 rule

A successful output-affecting mutation advances its page exactly once in the same PostgreSQL transaction as the mutation. The transaction updates `last_edited_at`, increments `scene_revision`, and returns the new revision. It must roll back together with the mutation; post-commit best-effort timestamp updates are not sufficient. No-op requests may conservatively advance the revision, but a failed or missing-target request must not.

Page reordering changes chapter navigation rather than page pixels and is excluded. OCR/provider/default settings that only govern future pipeline execution are excluded. The two global geometry settings (`textBoxPaddingPx`, `textBoxSafetyPercent`) are render-affecting and require a separate all-affected-page decision; they cannot silently remain cache-valid.
