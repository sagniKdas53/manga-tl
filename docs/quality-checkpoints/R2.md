## What the R1 evidence said, re-read before editing

- **sample61's 214 rows are one dedent.** `handlers/ocr.py`: the loop that turns merged unmatched groups into `direct_text` candidates sat *inside* the per-panel partition loop while `merged_unmatched` accumulated across partitions, so partition *k*'s regions were emitted (P − k + 1) times. R1's `stack.log` shows the five partitions merging to 15 / 15 / 16 / 14 / 3 = 63 distinct; 15·5 + 15·4 + 16·3 + 14·2 + 3·1 = **214**, exactly. Every duplicate was also a paid VLM crop and a translation row.
- **The wipe is the merge, then the plate.** No bubble → every fragment unmatched → one partition (no panels) → proximity chaining joins the free-standing columns into one component → union bbox 1011×1617 on sample83 → the bbox is not flat → `cover_fill_for_region` synthesises a rounded plate over it in the dominant colour → the builder paints it. The R2 row's "spanning more than one detector container" case is already handled per bubble and per panel; the one that was not handled is *no container at all*.
- **`AUDIT-R10`'s `_merged_mask_polygon` convex hull is gone** (replaced by `resolve_component_container`, which refuses a mask for incompatible containers). What remains of R10 is a fused YOLO detection covering two touching balloons — a detector output, not a merge decision. Measured below, not fixed here.

## What changed

**Worker** (`worker/`, submodule)
- `handlers/ocr.py` — `direct_text` emit loop dedented out of the partition loop (the 214 fix). `cover_fill_for_region(..., container_detected)`: with a detected container (YOLO balloon, or a contour the fallback found) the behaviour is unchanged; **free-standing text gets no synthesised plate** — a flat bbox keeps the honest bbox-rectangle erasure in its own median, anything else returns the local colour and `polygon = None`. `direct_text` candidates carry `containerDetected = bool(contour)`; `maskPolygon` is JSON `null` when there is no plate. Every grouping call passes the page area.
- `services/fragment_grouping.py` — `GroupingConfig.component_max_area_fraction` + `GroupingContext.page_area`. A component whose union box exceeds the fraction is regrouped at half the proximity budget, recursively, down to `MIN_THRESHOLD_RATIO = 0.05`, then to singletons. Off by default (frozen-behaviour contract of the module); `handlers/ocr.py` turns it on from `OCR_COMPONENT_MAX_AREA_FRACTION` (default **0.25**, the R2 gate).
- `services/translation.py` — `is_refusal` / `REFUSAL_PATTERN`, checked first in `is_valid_translation`. A refusal fails validation like any bad output, so it goes through the retry and per-region fallback passes and, failing those, is reported `translationFailed` → the backend creates the element hidden → the scene marks the region `review`. Narrower than the harness's `REFUSAL` regex on purpose: "I cannot believe you did that!", "Sorry... I can't go with you today", "I won't do this anymore!" are dialogue and stay valid (tested).
- `page_scene_renderer.py` / `handlers/render.py` — relay the renderer's `layout` in the callback.

**Backend** (`backend-rust/`)
- `page_scene_builder.rs` — `MAX_PATCH_PAGE_SHARE = 0.25`: a patch whose bounds exceed a quarter of the page is refused with a provenance warning and the text is drawn over source (belt and braces; the worker no longer produces such a region, old rows and wrong detector masks still exist). A `NULL` mask is the free-text case, not a warning. `style_for` sets `stroke` to the element's `background_color` — the halo colour.
- `coordinator.rs` — `box_shape` is set from `has_detected_bubble(region)` (R19 §3), not from `region_type`: `elliptical` only when a container was found, `rectangular` for free-standing text. `handle_render_callback(…, layout)`: stores the renderer's resolved layout in the ledger (`page_render_jobs.layout_json`, migration `20260919_render_layout.sql`) and writes each `text-<id>` object's `font_size` onto `layer_elements.size` for auto-sized elements, so the export's `project.json` (and R4's `ours font px` column) carries the size the page was actually set in.
- `routes/internal.rs` — render callback reads `layout`.

**Renderer** (`packages/page-scene/src/ContentScene.ts`, `services/page-renderer/`)
- Torii stroke rule: `STROKE_WIDTH_RATIO = 0.18` of the resolved font px (was 0.04), `stroke-linejoin`/`linecap: round`, and two passes — every line's stroke first (`fill="none"`), then every line's fill (`stroke="none"`), as `<g data-text-pass="stroke">` / `"fill"`. One `<text>` per line with `paint-order` let line 2's halo cover line 1's descenders at this width. No stroke colour → no stroke pass.
- `resolvedTextLayout(scene)`: `[{object_id, font_size, lines}]`, returned by `mountPageScene` and by `PageRenderer.render` as `layout`. `dist/scene-static.js` rebuilt.

**Editor** (`frontend/`) — the canvas is the judged surface and it had its own copy of the wipe. `maskPaint.ts` (the ZIP's mask layers) and `Reader.tsx` (the canvas) both filled the *text box* as well as the polygon for free-standing text — `free_text_box`'s padded and, for a narrow column, widened rectangle — and fell back to filling the whole box when there was no polygon. Now the polygon is the whole plate; a pipeline element (has a `regionId`) with no polygon paints nothing; a manual element with no polygon keeps its box fill, which is the user's plate tool. `paintLayerMask` loses its `regionsById` parameter. The editor's glyphs are HTML in a `foreignObject` and get no halo yet — that is M7's typography pass, and it means free text on artwork is currently more legible in the render than on the canvas.

**Harness** — `capture_quality_baseline.cjs --page name=path[:lang]` adds a named page outside the fixed lists (used for the p5 caption).

### What R2 keeps of R19, and what it leaves

- R19 §1 (plate padding 18 %, corners 22 %): moot for free-standing text — there is no plate. `cover_balloon_polygon` and `COVER_FILL_PAD_FRACTION` stay for the busy-balloon-interior case, which is the case they were written for.
- R19 §2 (tie the box to the plate): where a patch survives for free text it is the bbox rectangle itself — the glyph extent — and the text box is that rectangle grown by `FREE_TEXT_PADDING / 2 = 10 px` (`text_box_geometry`), same centre, same shape. The residual 10 px is the one dial, and it becomes per-element with `AUDIT-B18`/`F16`. Reshape still edits `mask_polygon`; with no plate there is nothing to reshape, which is the honest state.
- R19 §3 (`box_shape` from what was detected): done. The menu label "Elliptical (Contour-Based)" is now true whenever it appears.
- Not done: fill colour sampled from the source text (decision 2 says "fill colour taken from the source text"; ours is still `contrasting_text_color(background)`, black or white). Nearly all manga lettering is one of those two; noted for M7.

### Findings for other rows

- **`AUDIT-B16` (packet: "verify against R1"):** `handle_translation_callback` still inserts a new translation layer on every pass and hides the previous ones on a redo (`coordinator.rs`, the `INSERT INTO layers` after the `is_redo` block). sample177 finished with three translation layers, two hidden. R1's note that a QA retry "updates the existing Translation layer" is not what the code does; the *elements* are updated in place only within one layer. No pixel effect (hidden layers are not in the scene); the cost is one more layer per QA round. Answer for B16: the "redo made no new layer" report is not reproducible because a redo always makes one — the layer list grows, which may be the complaint. Leave to the B16 packet.
- **New, for R5:** re-uploading bytes the backend already has attaches the new page to the processed image, skips OCR and queues a bare `render` job with no scene, which fails three times (`render job carries no logicalScene`). Seen when the harness was relaunched on the same database. A page created from a deduplicated image needs its own OCR pass (or the existing regions copied) before a render can be queued.
- **Harness:** `--skip-rendered` is mandatory since R1; documented. A tool-bound launch dies at 10 minutes — run it under `setsid nohup`.
