## What changed on the page

The editor used to draw the page image, then the English, with a flat colour plate under each balloon. The export drew the worker's cleanup patches instead. So the editor showed Japanese under the English that the export had erased.

Now each cleanup patch is its own object on an **Inpainting** layer, drawn after the page image and before any text, in the same order, place and opacity as the export. A patch can be moved, resized, faded, hidden or deleted without touching the text, and the export follows. The flat plate is kept only for a region whose cleanup gave nothing.

| R7-D2 | When cleanup runs again (page OCR redo, layout redo, a merge), the old patches are **kept, hidden**, like old Translation layers. A patch whose region went away stays drawable if turned back on. |

Hiding a text layer or one text element keeps the patch, which is the blank page for hand lettering. |

### Persistence (project round trip)

Each page was exported from the editor as a project ZIP and imported into a new chapter:

| page | render: imported vs original | editor, original | editor, imported | imported editor vs its export |
| --- | --- | --- | --- | --- |
| sample177 | identical bytes (`7f330d9d…`) | 6 patches, 0 plates | 6 patches, 0 plates | — |
| sample93 | RGBA identical | 4 patches, 1 fallback plate | 5 patches (the plate became one), 0 plates | RGBA identical, 5/5 patches |

An imported page has no OCR regions, so it cannot ask a region anything. The first round trip (sample177) passed on renders but missed this. Its imported editor drew 6 flat plates the export did not. That is **fixed**:
- **The exporter bakes the region's verdicts in.** A patch on a shown layer is saved visible only if it is painted now (R7-D4). Text on a patched region loses its plate polygon.
- **The importer turns the polygon a region's text still carries into a patch** when the region is not on the new page. That polygon is its fallback plate. The builder's own plate rasteriser draws it (same pixels), and it paints after the other patches, where the builder painted plates.
- **The editor never plates region-less text**, because the export never does. "Add Mask" elements (no text) keep their editor-only plate, as before.

The id-free scene matches except in two expected ways. Text objects keep their content and boxes, but their stacking order changes, because import gives elements new ids and text z-order follows element id. That behaviour predates R7; it matters only where English overlaps (sample222 and sample99 have such spots). And on sample93 the plate is now a cleanup artifact. A byte-for-byte scene digest cannot match after import (new ids), so the gate is read as render digest plus id-free scene.

### Handles (real editor, real mouse)

On sample222, one patch with unset opacity (`handles/handles.json`):
- dragging its frame moved it;
- dragging the corner resized it;
- the opacity slider set 40 %.

Three presses of Ctrl+Z brought the saved row back exactly (x, y, size, opacity 1) and the export digest back to its start value. This run caught a bug before the fix: an Undo back to unset opacity left the server faded, because the save omitted the value. Saves now always send a patch's opacity.

### Fallback

sample93's one region with no patch and a plate: the plate is drawn in the editor and exported as a plate. No patched region draws a plate (`fallback_plate` in `behaviour.json`).

## Things found on the way

- **The capture harness was stale.** `capture_quality_baseline.cjs` looks for an "Export Rendered PNG" button that no longer exists. It also stopped every fixture on *any* FAILED job in the queue; it now stops only on the page's own, and the runs used `--skip-rendered`.
- **QA incomplete-verdict guard fired twice** (OQ-02 working as meant): sample61 (12 missing verdicts of 63) and sample83 (4). Their renders were already current, so the gate used them.
- **Import used to fail or mislink across pages.** `regionId` in `project.json` was restored as-is, which is a foreign-key failure on another database or a link to another page's region. It is now kept only if the region is on the target page.
- **Plain-mask review action and merge** could have rewritten Inpainting elements as if they were text; both now leave them alone (merge hides the absorbed regions' patches as history).
