# F03: bounded fused-container resolution

Status: **DONE**.

## Change

`merge_ocr_regions` retains an exact shared detector polygon only when **every** component member supplies the same valid local container. Missing or incompatible polygons produce `maskPolygon: null`, an explicit `containerResolution` review state, and retained `rawFragmentMembership`; no convex hull or remaining member's polygon is granted to the component.

Known distinct `panelId` values split a proximity component into local fragments before text concatenation. A shared panel remains non-evidence; this is only a veto for incompatible panels.

In the OCR handler, a multi-fragment YOLO bubble now accepts a crop only when `get_split_polygon` returns a local contour. A failed crop stores local fragment geometry, `maskPolygon: null`, `backgroundColor: null`, and `ownershipProvenance.containerResolution: "review-local-split-failed"` rather than reusing the full fused detector mask. This state cannot grant mask-based cleanup authority.
