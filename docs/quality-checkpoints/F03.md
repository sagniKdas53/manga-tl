# F03: bounded fused-container resolution

Status: **DONE**.

## Change

`merge_ocr_regions` no longer constructs a convex hull from incompatible detector polygons. `resolve_component_container` retains an exact shared polygon only when every member has the same valid container. Missing or incompatible containers result in `maskPolygon: null` and an explicit `containerResolution` review state.

Every merged or singleton output now carries `rawFragmentMembership`, retaining the in-batch fragment index and any stable `fragmentId`. A failed local-container decision therefore cannot grant cleanup authority over a whole fused detector mask; F04 can carry the preserved identities through the OCR callback and policy workflow.
