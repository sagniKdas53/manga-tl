# G2: revision-safe output lifecycle

Status: **PASSED**.

M2 now has current evidence across every mutation family and the queue-to-reader boundary. The gate is grounded in isolated PostgreSQL, Valkey, and MinIO services; it does not infer completion from timestamps alone.

## Trace evidence

`jobs_endpoints::recovery_reset_stale_and_debounced_render` executes one authoritative lifecycle trace against real services:

1. A page has an immutable revision-0 snapshot and an edit timestamp. The debounce recovery scan reserves exactly one render job and ledger row; a repeated scan deduplicates it.
2. A newer saved revision-1 snapshot exists while revision 0 remains queued. The next scan reserves the independent revision-1 job.
3. Revision 0 writes staged bytes and calls the real render callback. The callback archives its own revision-specific object but cannot set `current_render_job_id`. The actual `get_page_rendered` handler returns `409 {status:"pending"}`.
4. Revision 1 writes different staged bytes and calls the same callback. The page pointer advances only after the persisted ledger revision/digest matches the current snapshot; the actual handler returns `200` and exactly those immutable bytes. A duplicate callback does not advance the pointer again.
5. Revision 2 becomes current, then its ledger job is marked failed. The actual handler returns `409 {status:"failed"}`. A recovery scan creates a new reservation; while it awaits its own callback, the handler returns `409` rather than presenting revision 1 as current.

The trace covers deduplication, concurrent edit while work is queued, out-of-order callback delivery, immutable output identity, failed state, retry, and the public read boundary.

## Gate decision

G2 requirements are met. Page mutations create a new freshness state; current immutable snapshots are deduplicated by revision/digest; callbacks may retain old results but cannot make a newer edit complete; failures are visible and retryable; and grid, download, and export reads have no old-artifact or original-image fallback. M2 is complete. M4 and M8 may rely on the revision-safe output lifecycle, but no later renderer, SFX, grouping, or corpus gate is implied complete.
