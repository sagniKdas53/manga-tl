## Scope

E02 adds no editor integration, OCR overlay, browser service, queue transport, font acquisition, cleanup algorithm, or source-pixel mutation. It consumes E01's pure measurement-injected layout API. No existing production symbol was modified beyond the E01 package boundary; new scene symbols have no upstream callers yet.

## Implementation

- `resolvePageScene` consumes an explicit source, active cleanup assets, and styled text objects, then returns source-space line boxes and structured diagnostics.
- A visible blank manual object stays blank and produces `empty-manual-text`; it does not invent visible placeholder text.
- Rotated object bounds yield `object-clips-page` when they escape source dimensions. Text fitting overflow yields `text-overflow` rather than silent clipping.
- `renderPageSceneSvg` escapes content and emits only three ordered layers: source, cleanup, glyphs. Cleanup assets always precede glyphs; it emits neither OCR pixels nor editor handles.
- Styled glyphs preserve fill, stroke, weight, source-space rotation, and declared writing mode. This is the static trusted content entry for E03, not a user-supplied HTML renderer.
