## Implementation

- Added local package `@manga-library/page-scene` under `packages/page-scene/`.
- Moved fit-box insetting, line-centre clamping, polygon/ellipse/rectangle wrapping, finite inset guards, newline normalization, 1.2 line-height, 0.95 shape allowance, and clean/contained/height sizing tiers into the package.
- The core accepts a `TextMeasurer`; it neither creates a canvas nor accesses `document`.
- `frontend/src/utils/fitText.ts` now supplies the browser Canvas measurement adapter and keeps `ensureFontsLoaded` browser-only.
- `frontend/src/utils/textFitBox.ts` is a forwarding export. Reader SVG preview, PNG export, and ZIP export therefore consume one geometry implementation.
- Added the frontend local `file:` dependency and lockfile entry. No workspace manager or renderer service was introduced.
