# C02-R5: global geometry invalidation

Status: **DONE**.

`textBoxPaddingPx` and `textBoxSafetyPercent` feed both the Reader fitting configuration and worker render job payload. `update_settings` now persists supplied geometry settings and invalidates every page in one PostgreSQL transaction. A changed geometry value increments each page's `scene_revision` and stamps `last_edited_at`; an omitted or unchanged value increments none.
