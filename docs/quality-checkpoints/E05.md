# E05: amd64 pinned renderer deployment

Status: **DONE**.

`services/page-renderer/Dockerfile` uses the exact Playwright image digest `sha256:dcc5531e97840b9b5e794f2814476b21571c5124a3fca2267d73041f56e7580e`. It installs the existing pipeline default, Comic Neue, and rejects a font checksum other than `2728ee8f303e31934e62bf27b044fd7657b0613412d51f7444db1078cc3a7cb2`. `fonts.json` is the service registry: canonical font ID `comic-neue`, browser family `Comic Neue`, path, digest, and one reusable browser context. The service resolves a scene font ID to that registered browser family; the entrypoint repeats the checksum check before binding the HTTP listener.

Both Compose files define the `linux/amd64` `page-renderer` service with a 1 CPU / 2 GiB default limit and one-context configuration. The worker depends on its health check and receives `PAGE_RENDERER_URL=http://page-renderer:8090`. The endpoint is internal-only; no host port is published. Missing font assets fail at image build or process start. A missing renderer/service returns an adapter exception, preserving normal worker retry semantics rather than falling back to Pillow.
