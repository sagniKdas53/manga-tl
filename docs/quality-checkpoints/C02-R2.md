# C02-R2: transactional layer and element mutations

Status: **DONE**.

## Change

All successful layer/element create, update and delete routes now advance their owning page with `page_freshness::advance_page_revision` in the mutation transaction. Layer deletion resolves its page before cascade deletion; element deletion likewise resolves its owner before removing the element. `update_layer_element` resolves the parent layer's page rather than treating a layer UUID as a page UUID. Post-commit `touch_page` calls are removed from these write paths.

## Focused gate

`./scripts/test-env.sh run cargo test --test layers_endpoints layer_and_element_lifecycle_with_gating` passed against healthy isolated PostgreSQL, Valkey and MinIO. Its page begins at revision 0 and finishes at revision 12: page/image layer creation, layer order/visibility edit, element creation, changed and unchanged element saves, element/layer deletes and the four z-order layer creations each advance exactly once. The test did not early-return. `cargo fmt --check` passed; the temporary service stack was removed.
