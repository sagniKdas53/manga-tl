Status: **DONE** — `services/page-renderer/` provides a bounded, static Playwright renderer for the shared `packages/page-scene` SVG scene.

## Scope and impact

GitNexus was refreshed before E03. `resolvePageScene` and `renderPageSceneSvg` each had **0 upstream callers, 0 affected processes, LOW risk**. E03 adds a standalone service and does not modify the render queue, callback route, page revision ledger, worker handlers, editor, source pixels, or any holdout material. Those transport changes are E04.

## Implementation

- `services/page-renderer/build.mjs` bundles one trusted browser entry from the same shared scene source. The browser receives scene data, never arbitrary caller HTML or a scene-provided navigation URL.
- `PageRenderer` pins Playwright **1.62.1**, launches one reusable Chromium process, and bounds reusable browser contexts (`maxContexts`, default 1). Capacity exhaustion is explicit.
- It accepts only `page-scene/v1`, finite source-space scene geometry, SHA-256 render identities, and embedded PNG/JPEG/WebP source/cleanup assets. External URLs fail before browser work.
- Font IDs are configured server-side with exact SHA-256 and local paths. Startup reads and hashes each configured file, embeds its verified bytes into `@font-face`, waits for the exact weights used by visible text, and records the hash in the render result. Missing/unregistered/wrong-hash fonts fail visibly.
- The service waits for loaded fonts and images, captures the SVG at source dimensions with device scale factor 1, verifies PNG dimensions, and returns PNG SHA-256, diagnostics, page revision, scene/input digests, browser build, Playwright version, and font hashes.
- A visible blank manual object remains glyph-free and returns the layout diagnostic; cleanup assets render before glyphs.

The prototype font registry used the host's `DejaVuSans.ttf` only as a verified local test fixture (`690243adfefe0ce154b547db6205794bd30ac4277275179517a90994f4980648`). E05 must package the approved font asset into the amd64 renderer image; E03 does not claim that DejaVu is the final production typography choice.
