## Measurement and evaluation findings to close

- `rendered_preserved_or_review_regions` reads `qaStatus` starting with `reject`, not reviewed region actions. It cannot establish policy correctness.
- `merged_owner_elements` counts multiple elements per OCR ID, not multiple independent owners merged into one element. An existing region ID is also not proof of an independently reviewed owner.
- Rectangle overflow/overlap ignores actual glyphs, rotation and reviewed container boundaries. Keep these useful proxies named honestly; do not substitute them for G5/G7 evidence.
- Only sample416/sample609 have non-null stored font-size minima; all six originals and 22/24 controls lack them. Stored size is not proof of the final fitted font. The “24 px observed across every control” claim is unsupported.
- Threshold status is still `frozen-pending-coordinator-approval`. The comparator silently skips canvas dimensions and page-level overlap incidence, passes missing font measurements, hard-codes bounds and compares pooled totals rather than language/style slices.
- The former A09 next command would recursively score 77 historical pages, including reserves, instead of new candidate outputs for the frozen roster. It is withdrawn. D01/G01 now explicitly use development data, not A09 labels/crops.

Correct available measurements and explicitly record unknown/not-executed dimensions. Define how later pixel/render gates will be measured without implementing the new renderer in G0. Any revised thresholds/protocol must derive from development data, preserve the original frozen bytes and reference them through a versioned successor. Do not relax later hard requirements to match bad baseline output.
